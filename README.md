# GNOS-GitHub
I've seen this 'GNOS' thing on Snap, so I remade it on GitHub. (Credit to gimnotepad)

https://snap.berkeley.edu/project?username=gimpnotepad&projectname=GNOS

> [!NOTE]
> GNOS is not a real operating system, it was indefinitely made up by gimnotepad.
> GNOS was made with Snap!, a Scratch mod where you create your own blocks and make your dreams come true.

> [!NOTE]
> GNOS requires JavaScript Object Notation (.json),
> BrainTest's TypeScript Object Notation (.tson),
> BrainTest Simple Service (.btssv),
> and Python (.py) to run my version of GNOS.
